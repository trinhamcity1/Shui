Where this leaves it

Pairing A is final for everything Shui controls the background of — the app icon, splash screen, marketing, social. Ink is Shui's own surface there, never variable, so foam-on-ink stays the primary mark.

The burned-in video watermark is a different surface and needs its own pairing: ink word, current thread, on the whiteboard's own light background. That's not a stylistic choice, it's the only option in the set that's actually visible on what GolpoAI renders — this is worth re-checking against a handful of real generated frames once there's API access, since "whiteboard" backgrounds can still vary (a mostly-dark illustration moment, a colored highlight box) and the watermark needs to hold up against those too, not just a flat paper-white field.

Two pairings, two jobs, same mark. Next: clean up the curve so it threads through the actual letter counters instead of approximating the gap, lock exact stroke widths at three reference sizes (icon, watermark, full lockup), and prepare the SVG export set for both.
