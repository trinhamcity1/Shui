Where this leaves it

The italic wordmark works everywhere it was tested, so that part's close to settled unless something about it feels wrong in hand. Between the two icons — The Current reads slightly stronger as a corner watermark specifically, because a thin curved stroke stays legible against a busy video frame better than a filled shape does at 16px. The Vessel is still the more emotionally specific mark and the better icon-only choice for the app itself; nothing says it has to be the same mark doing both jobs.

If that split — Current for the burned-in watermark, Vessel for the app icon — sounds right, say so and I'll take each all the way to production-ready: exact geometry, a real font license check on Fraunces for commercial use, and an SVG export set.
